# **Vanilla Fluent Plus [VFP]**

## Description

Vanilla Fluent Plus (VFP) is full client-side Minecraft modpack that optimize the game, improve it visually adding several visual effect and add many quality of life features.

The modpack also include a preset for all the mod option and keybinds.
